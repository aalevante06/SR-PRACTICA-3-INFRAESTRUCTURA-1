# Running-configs

Configuraciones asociadas a la Práctica #3 — Infraestructura #1.

- `FortiGate-2174.conf`: backup completo de FortiGate sanitizado.
- `FortiGate-2174-relevant.conf`: extracto depurado con interfaces, DHCP, objetos, grupos, Web Filter, ruta y políticas relevantes para esta práctica.
- `ISP-2174.txt`: running-config del router ISP.
- `SW-USERS-2174.txt`: running-config del switch de usuarios.
- `SW-SERVERS-2174.txt`: running-config del switch de servidores.

## Seguridad

Los archivos destinados a publicación fueron revisados para ocultar secretos. Las contraseñas, claves y otros valores sensibles se representan como `<REDACTED>` cuando corresponde.

El extracto `FortiGate-2174-relevant.conf` es documental y no debe tratarse como un backup completo para restauración.
